# NeuroDrive-arduino
Controlling the speed of an RC car based on real-time EEG signal levels using Arduino
 <br /> <br /> <br /> <br />


  bluetooth module: BT-986

  You can receive EEG signals from BT-986 master. <br />
  BT-986 slave must be attached to the EEG device.
